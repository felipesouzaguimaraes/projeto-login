Este é o **Projeto Login**, desenvolvido como um dos desafios práticos principais do **Módulo 4** do curso de HTML5 e CSS3 do **Curso em Vídeo**. 

O grande objetivo deste projeto foi colocar em prática os conceitos de **formulários estruturados**, estilização avançada de campos de entrada (inputs), uso de ícones modernos e, principalmente, a aplicação de **Media Queries** para criar um layout totalmente responsivo com a filosofia *Mobile-First*.

## 📱 Funcionamento e Responsividade

O projeto foi construído pensando primeiramente na experiência em dispositivos móveis e depois expandido para telas maiores:

| Dispositivo | Comportamento do Layout |
| :--- | :--- |
| **Mobile (Celular)** | Exibe apenas o formulário centralizado na tela, otimizando o espaço para o preenchimento dos campos. |
| **Desktop (Telas Grandes)** | Graças ao arquivo `media-query.css`, o layout se expande horizontalmente, revelando uma imagem abstrata com tons roxos ao lado esquerdo do formulário de login sobre um fundo gradiente moderno. |

## 🛠️ Tecnologias e Recursos Utilizados

* **HTML5:** Estruturação semântica da caixa de login (`<main>`, `<section>`, `<form>`).
* **CSS3 Nativo:** Utilização de flexbox/grid para centralização perfeita, estilização dos botões, degradê de fundo e efeitos de foco.
* **Media Queries:** Arquivo separado (`media-query.css`) dedicado a controlar a quebra e expansão do layout.
* **Google Material Icons:** Inclusão de símbolos vetoriais dinâmicos para ilustrar os campos de e-mail e senha.

---

## 📂 Estrutura de Arquivos do Repositório

* `index.html` — Estrutura bruta e marcação do formulário.
* `estilos/`
  * `style.css` — Estilos gerais e base focada em Mobile.
  * `media-query.css` — Regras de transição para telas de Computador/Tablet.
* `imagens/` — Banco de imagens utilizado no plano de fundo e nas laterais do container.

## 🚀 Como Visualizar Localmente

Se preferir rodar o projeto localmente em sua máquina:

1. Baixe ou clone a pasta do projeto.
2. Dê um duplo clique no arquivo `index.html`.
3. Pressione a tecla **F12** no seu teclado para abrir as ferramentas de desenvolvedor do navegador e teste redimensionar a tela para ver a mágica da responsividade acontecer!
